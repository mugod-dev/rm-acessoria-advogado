# RM Assessoria e Legalização Imobiliária

Site institucional (página única) da RM Assessoria e Legalização Imobiliária.

## Como publicar no GitHub Pages

1. Crie um repositório no GitHub e envie o arquivo `index.html`.
2. No repositório, abra **Settings → Pages**.
3. Em **Branch**, escolha `main` e a pasta `/ (root)`, depois clique em **Save**.
4. Em alguns minutos o site fica disponível no endereço mostrado nessa mesma tela.
